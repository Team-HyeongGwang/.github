**Highlite** — Highlight + Lite

형광펜·필기펜으로 표시한 중요도 정보를 바탕으로

### 𝗣𝗿𝗼𝗷𝗲𝗰𝘁 𝗠𝗼𝘁𝗶𝘃𝗮𝘁𝗶𝗼𝗻

❗ 대학생의 시험 준비에서 발생하는 문제점
```
- 교수님이 제공한 PPT 위에 필기한 내용을 직접 문제로 만들기 어려움
- 형광펜, 필기펜으로 중요 표시를 해도 문제 출제에 활용되지 못함
- 직접 문제를 만드는 데 많은 시간이 소요됨
- 중요도에 따른 문제 유형 배분이 어려움
```

❗ 이에 대한 해결책
```
- RAG 기반 교재-필기 매칭
   - 임베딩 유사도로 필기 내용과 관련 교재 원문 자동 연결
   - 교재 원문 개념까지 반영한 문제 생성
- 형광펜·필기펜 중요도 자동 인식
   - 색상별 가중치 반영
   - 중요도에 따라 출제 비율 자동 배분
- AI 기반 자동 문제 생성
   - Claude Opus 4.5 + GPT-4.1 이중 모델 경쟁 구조
   - 평가 Agent가 품질 높은 문제 채택
- 개인화된 학습 경험
   - 오답 기반 문제 재생성
   - 사용자 피드백(Human-in-the-loop) 기반 문제 개선
```

### 𝗠𝘂𝗹𝘁𝗶-𝗔𝗴𝗲𝗻𝘁 𝗣𝗶𝗽𝗲𝗹𝗶𝗻𝗲

```
PDF 업로드
    ↓
RAG Agent              → PyMuPDF로 페이지별 이미지 변환
                         Gemini 2.5 Flash로 OCR + 형광펜·필기 색상 추출 + 청킹 (병렬처리)
                         OpenAI text-embedding-3-small으로 벡터화 → pgvector 저장
    ↓
중요도 분석 Agent       → 텍스트 + 시각 정보(형광펜·필기펜·별표·밑줄) 결합
                         중요도 점수 산출 
    ↓
문제 생성 Agent         → 중요도 순위에 따라 5:3:2 비율로 출제 비중 배분
                         Claude Opus 4.5 + GPT-4.1 동시 호출 → 문제 후보 생성
    ↓
평가 Agent              → 룰 베이스 사전 검증 → LLM 품질 검수
                         반려 시 교정안 생성 → 재생성 요청
    ↓
개인화 Agent            → 오답 시, 정답 시 가중치 차등 반영
                         오답 청크 우선 배정 → 맞춤 재출제
```

## 💡 𝗞𝗲𝘆 𝗙𝗲𝗮𝘁𝘂𝗿𝗲𝘀

| 기능 | 설명 |
|---|---|
| 🔍 멀티모달 PDF 파이프라인 | Gemini로 OCR + 형광펜·필기 색상 추출, Context Cache로 비용 절감 및 안정화 |
| 🖊️ 중요도 기반 출제 | 형광펜·필기펜 색상별 가중치 반영, 중요도에 따라 출제 비율(5:3:2)·유형 자동 배분 |
| 🤖 이중 모델 경쟁 구조 | Claude Opus 4.5 + GPT-4.1 동시 호출 → 평가 Agent가 고품질 문제 채택 |
| ⚡ 배치 병렬 처리 | asyncio.gather 기반 병렬 실행 → 생성 시간 3~4배 단축 (60~90초 → 15~25초) |
| 📚 RAG 기반 교재-필기 매칭 | 임베딩 코사인 유사도로 교재 원문과 필기 내용 자동 연결 |
| 🔄 Human-in-the-loop | 사용자 피드백으로 문제·해설 재생성 (최대 3회) |
| ✅ 이중 검수 구조 | 룰 베이스 사전 검증 + LLM 품질 검수, 반려 시 교정안 자동 생성 |
| 📝 오답 노트 | 틀린 문제 기반 취약 개념 파악 및 재출제 |
| 📄 요약본 생성 | 중요도 4.0 이상 청크 필터링 → 형광펜 색상 보존 학습 노트 생성 (PDF / MD) |
| 🔐 세션 기반 로그인 | 구글 로그인 연동, 개인화 학습 데이터 안전 관리 |
